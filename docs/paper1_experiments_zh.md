# 论文一实验计划：识别误差校准与恢复证书

日期：2026-10-24。对应推导稿：[PAPER1_GEOMETRY.md](../proofs/PAPER1_GEOMETRY.md)，重点为式 (1)、(2)、(23)、(26)、(27)、(28) 及第 9 节反例。以下实验尚未实施；已有代数检查见 [复现说明](../experiments/paper1/README.md)。不预设方法优于已有算法。

## 1 实验要回答的问题与目前已有证据

当前脚本检验的是精确总体矩阵、已知支撑与人为给定扰动下的公式一致性：它们有助于发现实现和常数错误，不能当作有限样本置信覆盖率实验，也不能证明定理或新颖性。

下一阶段应回答四个独立问题：

1. 在模型成立时，残差和真实方向误差的校准有多紧？
2. 有限样本和噪声下，法向估计与证书分别何时可靠、何时有用？
3. 谱间隙、混合条件数、遗漏目标和模型偏离怎样影响结果？
4. 相比只看 MCC 或训练损失，证书提供了哪些额外信息，同时还遗漏哪些问题？

零空间/最小特征向量与带归一化的常数拟合具有同一总体机制。实验贡献应围绕校准、证书和失效边界，不以这两种实现之间的算法优越性为卖点。

## 2 统一生成机制和数据协议

### 2.1 主实验：共享线性 DAG 与精确 clamping

- 潜变量维度 `d ∈ {5, 10, 20}`；主实验直接取 `p=d`、固定观测坐标 `Y=MZ+a`，避免把尚未证明的子空间估计误差混入主定理。
- 随机拓扑序与稀疏 DAG，预期入度约 2；非零边权随机取正负，固定生成规则并限制路径放大。另保留链图作为强相关压力测试。所有环境共享未被干预的结构方程和外生噪声分布。
- `Z=B^T Z+ε`，主分支为独立 `ε_j ~ Uniform[-s_j,s_j]`。每环境执行 `do(Z_i=c_i)`，切断目标入边并重新解剩余方程；不能把一份观测样本的第 i 列改成常数后当作干预样本。
- 完整覆盖分支含 d 个不同目标；未知生物学命名只意味着输出允许排列，不意味着允许遗漏或重复目标。
- `M=U diag(s) V^T`，U、V 为独立随机正交矩阵；奇异值几何均值固定为 1，条件数 `κ(M) ∈ {1, 3, 10, 30, 100}`。保存实际 `σ_min(N)`，因为混合条件数与单位法向矩阵条件数并不相同。
- 激励分支选择一个外生噪声尺度 `s_j* ∈ {1, 0.3, 0.1, 0.03}`，其余为 1。报告每环境实际非零谱及 `α_min`，不能以生成参数代替谱间隙；改变该尺度也改变信号强度，这正是此对照测量的因素。
- 主结果沿单一因素扫描；只在预先选定的少量点研究“高条件数 × 弱激励”，不做全部参数的笛卡尔积。

对于均匀外生噪声，每个无噪环境可写成 `Y_i=μ_i+A_i u`，`u ~ Uniform[-1,1]^(d-1)`。保留 A_i，使总体协方差 `Σ_i=A_i A_i^T/3`、宽度 `ω_i(w)=2||A_i^T w||_1` 可精确计算。一个可验证的几何界为 `r_i=σ_min(A_i)`、`R_i=√(d-1)||A_i||_op`，其保守性也需披露。

### 2.2 噪声、样本与隔离

- 有界各向同性测量噪声：在固定 Y 坐标中加入独立均值零向量，其各坐标为 `Uniform[-√3 σ_i, √3 σ_i]`，故协方差为 `σ_i² I`；扫描 `σ ∈ {0, 0.02, 0.1, 0.3}`。主扫描固定环境间 σ，再测试不同环境不同 σ。
- Gaussian 信号或测量噪声用于二阶矩/谱估计压力测试；没有补充相应集中定理前，不能给它套用式 (28) 的有界样本 95% 证书。
- 每环境训练样本量先用 `N ∈ {d-1, d, 2d, 100, 300, 1000, 3000, 10000}`，删除重复值。训练数据、独立测试数据、不同重复试验均使用分开的随机流。
- 经验协方差统一使用样本均值中心化、分母 N，与推导式 (28) 保持一致。
- 独立测试集用于报告 held-out 损失和 MCC；可取每环境 `N_test=10000`，同时报告精确总体损失以分离测试集误差。总体量只用于合成评价，不能作为真实场景算法输入。
- 主定理允许同一批数据训练 W 和构造证书；专门保留这个分支检验统一界。另设独立校准集作为对照，不能把额外样本收益归因于定理本身。
- 每个固定生成模型分别重复采样并报告结果；模型种子与样本种子分开。覆盖率正式实验优先选 6–12 个固定模型配置，每配置 500–1000 次独立采样；预实验仅 30 次。不能把相关候选 W 当作独立重复扩大统计样本数。

### 2.3 比较对象与候选编码器

| 对象 | 用途与公平约束 |
|---|---|
| 每环境 PCA 最小特征向量 / covariance nullspace | 主要恢复器；取最小特征值对应方向，含重根时记录子空间维数和任意选向的不确定性 |
| 单位范数下的常数拟合 | `min_{||w||=1,c} mean[(w^T Y-c)^2]`；与前者是同一经验目标，比较只验证实现与优化误差；标明与 Ahuja 的常数拟合机制的关系 |
| 精确样本宽度最小化、平滑宽度可选 | 比较估计偏差、噪声敏感性、平滑偏差和计算成本；不能预设恢复更好 |
| 真法向 N、符号排列版本 | 只作 oracle 评价基准，不能作为可部署算法 |
| 预设扰动、随机单位行、重复行候选 | 检查证书对任意候选成立，而不是只对经验最优解成立 |
| 仅观测 PCA / 强制正交编码器 | 失败对照；真实法向一般不正交，不把它包装成充分竞争基线 |

数据学习的 W 与由真值生成的校准候选分别标记。所有结果使用相同数据、预处理、单位行规范和匹配规则；不静默做非正交 whitening，因为这会改变 Δ 及校准常数。

### 2.4 必须统一记录的指标

- `Δ(W)`：按式 (10) 做符号和一一排列匹配。对平方距离使用 Hungarian assignment，不能让多个环境复用同一行；d=20 时不能穷举排列。
- 训练、held-out、精确总体的宽度/方差损失；`m_Q`、`G_Q`、经验对应量。宽度和协方差目标各自求最优匹配，不能复用 Δ 的匹配。
- 每环境 `λ1, λ2, λd`、实际 `α_i`、估计谱间隙；`rank(N_hat)`、`σ_min(N_hat)`、条件数。数值秩阈值与实际稳定性阈值分别记录；全秩不代表数值稳定。
- 证书区间 `[L,U]`、覆盖指示、区间长度 `U-L`、`U<√2` 的非平凡比例、`underline α>0` 的可认证比例；另外预设实用阈值如 `U≤0.2` 并解释其方向距离含义。
- 每个环境的 `||Q_hat-Q||_op`，用于事后检查扰动事件；它不能作为 data-only ε 输入。
- MCC 使用相同独立评价分布、一一匹配的绝对 Pearson 相关；可另报告 Spearman，但不要混合命名。MCC 衡量统计相关，Δ 衡量规定坐标中的方向距离，二者没有无条件等价关系。
- 时间、内存和样本总量；不把正常数的小耗时差异写成算法创新。

## 3 实验一：总体校准、尺度与条件数

**假设。** 在完整覆盖和充分激励下，式 (1)、(2) 的界成立；归一化、匹配和条件数信息不可省略。该实验是扩大代数排错与展示校准松紧，仍不属于统计覆盖验证。

**设计。** d=5/10/20，各取若干固定 DAG 与 M。对 oracle N 做切向旋转，形成从近真值到远离真值的单位行候选；加入随机候选与不同符号排列。沿 κ 和激励尺度扫描，直接使用精确 A_i 计算总体量。

**对照。** 删除单位行规范并令 `W=tW0, t→0`；重复使用编码行的错误匹配；强制 W 正交。另验证修改固定观测坐标后 Δ 的数值会变化，避免误称坐标不变指标。

**图与指标。** `E_width` 对 Δ、`C` 对 Δ²散点及理论上下界；归一化比值、最紧/最松配置、`σ_min(N)` 与解混误差；按 κ 分面。

**验收。** 正确实现下无超出预先规定数值误差的界违反；已知失败对照确实暴露零损失退化或不可达到真解。观察到界很松也是结果，不能只展示挑选出的近等号案例。

## 4 实验二：有限样本恢复与训练零残差

**假设。** 无噪 clamping 且连续分布时，N≥d 即可几乎必然恢复法向；N<d 存在额外经验零方向。有噪时恢复误差随采样扰动/谱间隙变化，不能用“训练损失为零”替代恢复成功。

**设计。** 扫描 N、d、κ、实际 α 和有界各向同性 σ。主要比较 PCA-nullspace 与约束常数拟合，宽度方法作诊断对照。保存所有重复，不因法向矩阵病态而丢弃试验。

**图与指标。** Δ 对 N 的分位数曲线；Δ 对 `max_i ||Q_hat_i-Q_i||_op/α_i`；训练/held-out 差距；法向数值秩、最小奇异值和方向方差。

**验收。** 无噪充分样本达到数值精度；小样本对照显示零训练残差可以与非零总体误差并存。两种代数等价目标在优化充分时应一致；若有差异先检查求解器和容差。仅在固定非退化配置、噪声非零且进入渐近区间时估计 log-log 斜率，不强制所有点拟合 −1/2。

## 5 实验三：真正的 95% 证书覆盖与有用性

**假设。** 在有界噪声、模型成立且 L_i 为有效确定上界时，式 (28) 支持式 (26) 的无条件同时覆盖。正确覆盖不等于区间有用；保守证书可能长期退化为 `[0,√2]`。

**先做样本量可行性检查。** 使用生成机制给出 `L_i ≤ √(d-1)||A_i||_op + √(3d)σ_i`，不能用样本最大范数替代。这是受控实验预先提供的有效范围上界，不宣称解决未知 L 的部署问题。先求使 `2 ε_i(N)<α_i` 的粗略 N 门槛并打印；这里 α 真值只用于 oracle 可行性诊断，正式区间仍使用经验谱与理论 ε。在 d=20，即使 N=6400，当前 Hoeffding 界也可能完全空泛；病态混合或弱激励会进一步恶化。门槛若远超计算预算，仍报告“当前显式界在计划样本规模内为空”，不通过偷偷调小 ε 或换成 bootstrap 把它变成有效证书。

**设计。** 预先固定 6–12 个可代表易/难场景的模型，δ 主值 0.05，补充 `{0.01,0.1}`。每个模型每个 N 做 500–1000 次独立数据重复。候选集合含训练得到的 W、真 W、固定扰动、随机 W；每次重复额外记录“本次全部受测候选均覆盖”的事件，对应统一性检查。

**区间协议。** 若 `underline α≤0`，输出有效但平凡的 `[0,√2]`，并显式标记拒绝认证稳定性（abstention），不能丢弃此重复，也不能把它记为有用证书成功。另记录可认证但上界仍为 √2 的平凡情况。理论控制的是所有抽样重复中的错误认证概率 `P(返回有效性声明且真误差落在区间外)≤δ`；等价的全样本区间版本在拒绝时回退到全域。总体失败率、拒绝率、非平凡比例和条件于返回后的描述性覆盖分开报告；条件覆盖不保证 ≥95%。式 (27) 的直接法向估计上界单列，不与任意 W 的式 (26) 混成一种速率。

**图与指标。** 全样本错误认证率和二项区间；全候选同时覆盖率；拒绝率、区间长度、非平凡比例、`U≤0.2` 比例随 N、δ 的曲线；直接谱界和通用残差界的宽度比较。全域区间的高覆盖必须同时展示其零信息量，不得仅报告覆盖率。

**验收。** 使用预先指定的单侧精确二项检验筛查显著超过 δ 的全样本错误认证率，并对预设配置数量做多重检验调整。未发现显著失败不等于证明覆盖保证；有限重复也不要求观测比例机械地大于 95%。任何精确事件 (24) 成立却出现式 (26) 不覆盖的情况，是优先修复的公式或实现错误。若区间始终平凡，覆盖实验完成，但“可用证书”主张不成立，应先改进集中界/实验尺度。

**不得混淆的补充。** 用 oracle 实际算子误差或模拟分位数代替 ε 可展示“集中界是否是瓶颈”，但必须标成不可部署诊断；没有额外证明时不称严格 95% 证书。

## 6 实验四：噪声和近似干预的边界

**假设。** 固定观测坐标中的各向同性测量噪声只抬高谱底，不改变真法向；未知各向异性噪声和近似 clamping 可能改变最小特征向量。误设不能自动由 m_Q 或 G_Q 分类。

**设计。** 在相同 SCM、相同采样预算下比较：

1. 精确 clamping + 有界各向同性噪声（定理内）。
2. 精确 clamping + 旋转的各向异性噪声（边界外）；显式选择有 off-diagonal 耦合的协方差，不能只用与法向恰好对齐而保留最小特征向量的噪声。
3. `Z_i=c_i+τ ξ_i`，并让变化沿下游结构传播（随机/近似 clamping）；扫描 τ 和相对于原 α 的比值。
4. 保留残余父节点影响的软干预（可选），与第 3 项分别标记。

**对照。** oracle 已知噪声协方差扣除，仅展示额外标定的价值，不当作未知噪声方法。若补充已知模型偏离预算 η 的证明，再加入 `ε+η` 证书；在证明完成前只报告 `||Q_actual-Q_ideal||_op` 与误差，不把它冒充现有定理覆盖范围。

**图与指标。** Δ、谱底、G_Q、法向矩阵秩、朴素证书覆盖随 σ/τ/anisotropy 的变化；同一正残差在不同生成原因下的例子。

**验收。** 定理内的数值与统计检查继续成立；定理外出现失败被完整报告。若某一误设实例仍成功，只说明该实例可恢复，不反向验证一般定理。实验证实的是鲁棒范围，而不是从单个分数识别噪声原因。

## 7 实验五：负对照与 MCC 的信息边界

**假设。** 完整覆盖、线性函数类、充分激励和共享 SCM 不能被零残差替代；MCC 与方向误差/证书回答不同问题。

**设计与预期现象。**

- 仅覆盖 `k∈{1, floor(d/2), d−1}` 个目标：报告 Δ_I 与完整 Δ，构造已覆盖行正确、未覆盖行混合的 W；检查部分残差为零但完整误差非零。
- d 个环境却重复目标：展示“环境数等于 d”不等于完整覆盖，记录法向独立方向数；禁止以重复环境复制满足理论前提。
- 强相关链 DAG：选混合候选使 MCC 看似较高但 Δ 非零；同时在近独立 DGP 比较，避免把相关性带来的假象称为普遍现象。
- 精确复现推导稿 §9.2 两个数据不可区分模型；同一编码器具有相同可观测残差而不同真值误差。此处核对精确分布/参数关系，不用有限样本检验“没拒绝”冒充相同分布证明。
- `f(z1,z2)=(z1 exp(a z2),z2)`，每变量只在零值干预：对应坐标残差和重建误差为零，第一输出仍有跨变量依赖。线性 Δ 不直接用于该非线性 f，改报告 `∂f1/∂z2` 和对真变量的函数依赖；它是线性定理的边界，不是定理反例。
- 推导稿 §7 的非模块 SCM 环境族：几何残差为零，仍不存在符合全部环境的两节点共享 DAG。展示几何证据与因果机制验证的差别。

**验收。** 每个负对照出现其解析预期现象；任何方法若用“零残差”宣告完整识别，应在报告中标为无依据判定。MCC 只作并列指标，不宣称单独诊断全部纠缠，也不宣称 Δ 对所有任务都优于 MCC。

## 8 实验六：真实 Light Tunnel，仅作边界压力测试

**启动条件。** 前五项完成且主证书的有效范围、非平凡比例已明确后再启动。真实数据处理、传感器选择、干预协议和可用重复数须单独记录。

**假设。** 非线性、非确定性的观测过程超出当前固定线性坐标和各向同性噪声条件；此实验检验方法遇到现实偏离时呈现什么行为，不验证本文 95% 定理。

**设计。** 将可获取的真实干预数据与匹配的确定性模拟、受控添加噪声的模拟逐层比较。优先选择能明确固定目标的子集；不能把随机目标干预重新标成 deterministic clamping。使用同一预处理和训练/测试划分；学习非线性编码器或 PCA 子空间时明确新增假设及误差来源。

**指标与验收。** 报告 held-out 常数残差、谱底、谱间隙、法向矩阵稳定性及有真值时的表征评价，不把线性 Δ 或严格置信覆盖解释强加于任意非线性编码。真实/模拟表现差异不能单独定位所有失败原因。无论成功或失败均报告；成功不证明一般非线性 CRL 已解决。

## 9 交付格式和停止规则

建议保存配置、逐次重复 JSONL/Parquet、聚合表、图及生成脚本；记录版本、依赖和随机种子。图和表从原始重复记录重新生成，避免只保留均值。

至少交付：总体校准图；N–Δ 曲线；N–覆盖率与区间长度/非平凡比例并排图；噪声偏离图；负对照表；全部异常清单。展示 κ、α、σ_min(N) 的实际值，不能只给抽象难度标签。

出现下列任一情况先停止扩大计算：模型内代数界失败；已知扰动事件成立时证书不覆盖；协方差/constant-fitting 在相同约束下出现未解释差异；数据生成未共享未干预机制；所有配置在预设规模内只能输出平凡证书。最后一种意味着需改进有用性，不意味着数学定理错误。

## 10 最小下一步：先建立可复现的 pilot

先只实现实验二、三的共同管线，不接真实数据、不训练神经网络：

1. `d=5`，一个固定稀疏 DAG，`κ(M)=3`，完整目标覆盖，外生均匀噪声，固定观测坐标。
2. `σ∈{0,0.05}`，`N∈{4,5,20,100,300,1000}`，每配置 30 次独立样本重复；δ=0.05。
3. 恢复器为最小特征向量；候选补充 oracle N、两档固定方向扰动和随机单位行 W。全部使用精确一一匹配。
4. 输出每次 Δ、训练与 held-out 损失、实际算子误差、理论 ε、经验谱间隙、法向秩/条件数及证书 `[L,U]`。正式覆盖检验留到扩大重复后。
5. 在采样前报告式 (28) 达到非平凡认证所需 N 的估计；pilot 若全为平凡区间，明确写出原因。另对比“使用 oracle 扰动预算”的诊断图，判断主要松弛来自集中界还是几何校准。

pilot 的通过条件是：无噪 N≥5 正确恢复，小样本失效被展示，等价目标一致，证书代数无错，数据/图可以重跑。它不是论文统计结论。通过后再扩展 d=10/20、弱激励和正式覆盖；若证书过于保守，优先改进有限样本界而非堆更多实验。

## 参考与定位

- [Ahuja et al., ICML 2023](https://proceedings.mlr.press/v202/ahuja23a/ahuja23a.pdf)：确定性干预、常数拟合与近似识别的直接相关基线。
- [Squires et al., ICML 2023](https://proceedings.mlr.press/v202/squires23a/squires23a.pdf)：随机完美干预与精度矩阵方法，不能与 clamping 零空间机制混同。
- [Light Tunnel v3](https://arxiv.org/html/2502.20099v3)：现实噪声及合成消融的参考；真实数据实验需单独核对干预协议。
